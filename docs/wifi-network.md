# Wi-Fi & Network Connectivity

## Common Issue: Cannot Connect to Office Wi-Fi

**Troubleshooting Steps:**
1. Confirm the employee is selecting the correct network name: "CompanyCorp-Secure" (not the guest network, which has limited internal access).
2. Forget the network on the device and reconnect, entering credentials fresh (corporate Wi-Fi uses the same username/password as the employee's main account).
3. Restart the device's Wi-Fi adapter (toggle Wi-Fi off and on).
4. Move closer to an access point — some office areas have known weak coverage (check the office Wi-Fi coverage map on the intranet).
5. If the employee has confirmed correct credentials and is in a covered area but still cannot connect, escalate — this may indicate a device certificate issue requiring IT to manually re-register the device.

## Common Issue: Intermittent Wi-Fi Drops (not VPN-related)

**Troubleshooting Steps:**
1. Confirm this is general Wi-Fi dropping (affects all apps/browsing), not specifically the VPN client (see VPN Troubleshooting guide if VPN-specific).
2. Check if other employees nearby are experiencing the same issue — if yes, this is likely an access point issue and should be escalated immediately as a broader outage.
3. If isolated to one employee, try forgetting and reconnecting to the network, and restarting the device.

## Common Issue: Slow Internet Speeds

**Troubleshooting Steps:**
1. Run a speed test and compare to the office's expected baseline (~100 Mbps down).
2. Check how many devices/apps are active — heavy video calls or large downloads by the same user can cause perceived slowness that isn't a network fault.
3. If speeds are consistently far below baseline company-wide, escalate as a potential infrastructure issue.
