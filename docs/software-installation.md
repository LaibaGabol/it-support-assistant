# Software Installation & Access Requests

## Common Issue: Need New Software Installed

**Troubleshooting Steps:**
1. Check the Company Software Portal first — most standard business software (Zoom, Slack, Adobe Reader, etc.) is available for self-install without IT involvement.
2. If the software is not listed in the portal, it requires manager approval before installation — this is a policy requirement, not a technical limitation.
3. Once approved, installation requests for non-standard software should be escalated to IT with the software name, version, and business justification.

## Common Issue: Software Won't Open / Crashes on Launch

**Troubleshooting Steps:**
1. Restart the computer — this resolves a large share of "won't open" issues caused by stuck background processes.
2. Check for pending software updates (most crash issues are fixed in the latest version).
3. Try running the application as administrator (right-click > Run as administrator) to rule out a permissions issue.
4. Uninstall and reinstall via the Company Software Portal.
5. If the issue persists after reinstall, escalate with the exact error message shown (screenshot recommended).

## Common Issue: Insufficient Permissions / Access Denied

**Troubleshooting Steps:**
1. Confirm the employee is logged into the correct company account, not a personal or guest profile.
2. Check whether the resource requires a specific access group membership — this is common for shared drives and internal tools.
3. Access group membership changes require manager approval and cannot be self-served — escalate with the specific resource name and manager's name for approval routing.
