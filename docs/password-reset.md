# Password Reset & Account Access

## Common Issue: Forgot Password

**Troubleshooting Steps:**
1. Direct the employee to the self-service password reset portal at password.company.com.
2. They will need to verify identity via their registered personal email or phone number (set up during onboarding).
3. If the employee no longer has access to their registered recovery email/phone, self-service reset is not possible — this requires escalation to IT for manual identity verification and reset.
4. Passwords must be at least 12 characters, include one number and one symbol, and cannot match any of the last 5 passwords used.

## Common Issue: Account Locked Out

**Symptoms:** "Account locked" message after multiple failed login attempts.

**Troubleshooting Steps:**
1. Accounts lock automatically after 5 failed login attempts within 15 minutes, and unlock automatically after 30 minutes.
2. If the employee needs immediate access and cannot wait 30 minutes, this requires escalation for a manual unlock.
3. Confirm the employee isn't accidentally using an old cached password (common after a recent password change) — clearing saved credentials in the browser or system credential manager often resolves this.

## Common Issue: MFA (Multi-Factor Authentication) Not Working

**Symptoms:** Not receiving MFA push notifications or codes.

**Troubleshooting Steps:**
1. Confirm the Authenticator app is installed and the employee is checking the correct device (some employees have MFA registered on an old phone).
2. Check phone has an active internet or cellular connection to receive push notifications.
3. Try the backup method: manually entering the 6-digit code from the Authenticator app instead of waiting for a push.
4. If the employee has lost or replaced their MFA device entirely, this requires escalation — MFA device re-registration requires identity verification that cannot be done via self-service.
